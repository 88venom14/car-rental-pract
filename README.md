# Прокат автомобилей

Учебное настольное приложение для ведения автомобилей, категорий, клиентов и договоров аренды. Python отвечает за интерфейс и правила предметной области, а MySQL хранит записи и обеспечивает внешние ключи. Табличные операции находятся в `app/repositories.py`; tkinter не содержит SQL, кроме формирования аналитического отчёта в текущем прототипе.

## Запуск

1. Установите Python 3.11+, MySQL 8.0+ и единственную внешнюю библиотеку: `python -m pip install mysql-connector-python`.
2. Выполните `schema.sql` в MySQL Workbench либо командной строке. Скрипт создаёт `car_rental` и демонстрационные записи.
3. При необходимости задайте `CAR_RENTAL_DB_HOST`, `CAR_RENTAL_DB_PORT`, `CAR_RENTAL_DB_USER`, `CAR_RENTAL_DB_PASSWORD`, `CAR_RENTAL_DB_NAME`.
4. Из каталога `car_rental` запустите `python main.py`.

Пароль по умолчанию пустой, но реальные параметры подключения следует задавать через переменные окружения. Ошибки подключения и SQL фиксируются в `app.log`.

## Структура

- `main.py` — запуск tkinter.
- `config.py` — параметры подключения и коэффициент просрочки.
- `schema.sql` — структура четырёх таблиц и демонстрационные записи.
- `app/db.py` — подключение, транзакции и логирование ошибок.
- `app/repositories.py` — SQL-операции для таблиц.
- `app/services.py` — расчёт стоимости, просрочка, доступность и сценарии договора.
- `app/validators.py` — проверки полей.
- `app/ui/main_window.py` — вкладки, формы, поиск, сортировка и отчёт CSV.
- `tests/` — тесты бизнес-правил и валидаторов без GUI/БД.
- `materials/` — протокол и материалы отчёта.

## Правила расчёта

Период считается в календарных сутках между датами; для одной даты применяется минимальная оплата за сутки. При возврате раньше срока стоимость рассчитывается по фактическим суткам. Просрочка тарифицируется по коэффициенту 1.5. Тариф сохраняется в договоре на момент создания. Периоды проверяются как полуоткрытые интервалы, поэтому новый договор может начинаться в дату планового возврата предыдущего.

## Ограничения учебной версии

Интеграционные проверки требуют отдельной БД `rental_test`. Сначала выполните `schema_test.sql`, затем задайте `CAR_RENTAL_RUN_INTEGRATION=1` и запустите тесты; они создают и удаляют собственные тестовые строки. Экран договора содержит поля идентификаторов автомобилей и клиентов, чтобы минимизировать дополнительные зависимости интерфейса. Скриншоты следует снять на компьютере с настроенной БД и tkinter.
